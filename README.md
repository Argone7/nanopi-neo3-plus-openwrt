# OpenWrt 25.12.6 для NanoPi NEO3 Plus

Первый образ для NanoPi NEO3 Plus на RK3528A рассчитан на загрузку с microSD,
консоль UART0 и один порт Gigabit Ethernet с PHY RTL8211F. Для microSD выбран
режим High Speed на 3,3 В. RJ45 назначается в LAN стандартными настройками
Rockchip. Адрес по умолчанию — `192.168.1.1/24`, на LAN работает DHCP.

## Сборка в GitHub Actions

Поместите файлы проекта в репозиторий GitHub. В разделе **Actions** запустите
**Build NanoPi NEO3 Plus firmware** через **Run workflow**. Сборка также
запускается при push и pull request.

1. Задание **Build RK3528 U-Boot** собирает U-Boot v2026.07 и публикует
   `u-boot-rockchip.bin` с контрольной суммой. Конфигурация и раннее дерево
   устройств основаны на NanoPi Zero2. Бинарники DDR и BL31 взяты из той же
   ревизии Rockchip `rkbin`, что использует OpenWrt 25.12.6.
2. Задание **Build OpenWrt 25.12.6** скачивает этот артефакт, проверяет SHA-256,
   применяет патчи к OpenWrt v25.12.6 и встраивает загрузчик в SD-образ на LBA 64.
   Загрузочный и корневой разделы используют ext4. Задание публикует образ,
   итоговый конфиг, ревизию исходников и контрольные суммы.

## Запись образа и первый запуск

Скачайте артефакт `nanopi-neo3-plus-openwrt-25.12.6-ext4-*`. Проверьте
`sha256sum -c SHA256SUMS` в распакованном каталоге. Запишите
`openwrt-25.12.6-rockchip-armv8-friendlyarm_nanopi-neo3-plus-ext4-sd.img.gz`
на microSD утилитой записи дисковых образов. Если утилита не читает gzip,
сначала распакуйте файл. Назначение файла — первоначальная запись на карту.

- Для первого включения выньте модуль eMMC, если он установлен.
- Подключите USB–TTL адаптер **3,3 В** к GND, RX и TX отладочного разъёма.
  Параметры консоли **1500000, 8N1**, управление потоком отключено. Подавайте
  питание на плату отдельно.
- В журнале UART проверьте переход от U-Boot к Linux 6.12.112 и появление
  консоли OpenWrt. Проверьте модель платы и корневой раздел.
- Подключите гигабитный порт ПК или коммутатор. На плате выполните
  `ethtool eth0` и проверьте `Speed: 1000Mb/s`, `Duplex: Full` и
  `Link detected: yes`. С ПК в LAN проверьте `ping 192.168.1.1`.
  Первый пароль root можно задать командой `passwd` в UART-консоли.

## Локальная сборка

В Ubuntu 24.04 x86-64 установите зависимости, перечисленные в workflow, и
запустите команды от обычного пользователя. Для исходников OpenWrt требуется
регистрозависимая файловая система и путь без пробелов. В WSL используйте
файловую систему дистрибутива.

```bash
bash scripts/build-uboot.sh out/uboot
bash scripts/build-openwrt.sh out/uboot/u-boot-rockchip.bin out/firmware
```

`UBOOT_BUILD_DIR` и `OPENWRT_BUILD_DIR` задают каталоги для временных исходников
и сборки. `BUILD_JOBS` задаёт число параллельных процессов. Если сборка OpenWrt
оборвётся, скрипт напечатает путь к каталогу для диагностики.

Аппаратная проверка этого порта ещё предстоит. Источники разводки платы и
проверенный пример загрузки на ней доступны в
[схеме FriendlyElec](https://wiki.friendlyelec.com/wiki/images/a/ae/NanoPi_NEO3_Plus_2601_SCH.pdf)
и [PR Armbian #10409](https://github.com/armbian/build/pull/10409).
